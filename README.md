## 📦 Overview

Welcome to my personal portfolio website!

I'm **Aniket Sundriyal**, a final-year B.Tech Computer Science and Engineering student at Uttaranchal University.

This portfolio showcases my technical skills, development projects, learning journey, and experience in software development.

The website is built using **Next.js, React, Tailwind CSS, and Framer Motion**, with a focus on responsive design, interactive animations, and a modern dark-themed interface.

## ✨ Features

- 🏠 **Home Page** – Personal introduction, animated text, and profile section.
- 🌌 **Interactive Starfield Background** – Animated stars with mouse interaction and subtle glow effects.
- 👨‍💻 **About Section** – Personal background, skills, and professional information.
- 💻 **Projects Showcase** – Project cards with descriptions, technologies, GitHub repositories, and live demos.
- 📱 **Social Links** – Quick access to GitHub, LinkedIn, LeetCode, and email.
- 📄 **Resume Download** – Downloadable PDF resume.
- 📬 **Contact Section** – Contact page and navigation.
- 🎨 **Modern UI** – Dark theme, glassmorphism, gradients, and hover animations.
- ⚡ **Framer Motion Animations** – Smooth page transitions and interactive effects.
- 📱 **Responsive Layout** – Designed for desktop and mobile screens.

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/GxAniket/AniketPortfolio-React.git
```

**2. Navigate to the project directory**

```bash
cd AniketPortfolio-React
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in your browser**

```text
http://localhost:3000
```
